# Smart Resume Analyzer

A sleek, professional-grade, client-side web application that empowers students and professionals to receive instant, actionable feedback on their resumes.

## Overview

The **Smart Resume Analyzer** provides a robust, visually engaging interface for users to upload or paste their resumes and instantly get detailed analysis. Designed with modern UI/UX principles—featuring vibrant colors, glassmorphism, and dynamic micro-animations—the application ensures the resume review process is encouraging and highly interactive.

## Key Features

- **Instant Resume Evaluation:** Upload documents (.txt, .pdf, .docx) or paste resume text directly into the application.
- **Strength Scoring:** Get a clear, percentage-based score indicating the overall strength of the resume based on key metrics.
- **Keyword & Skill Analysis:** The analyzer identifies present skills and highlights critical missing keywords relevant to the industry.
- **Actionable Feedback:** Receive "alive," encouraging, and professional copy with tailored suggestions to improve the resume's impact.
- **Client-Side Processing:** All robust file parsing and keyword-based analysis logic run securely and instantly within the user's browser.
- **Premium UI/UX:** Enjoy a beautiful, responsive design with smooth CSS animations, hover effects, and a centered input section that seamlessly expands into a dynamic results dashboard.

## Tech Stack

- **HTML5:** Semantic structure for a clean layout.
- **CSS3 (Vanilla):** Custom styling, dynamic animations, modern typography, and a polished design system without reliance on heavy frameworks.
- **JavaScript (Vanilla):** Robust client-side file parsing, document type handling, and keyword analysis logic.

## Getting Started

Since the Smart Resume Analyzer is completely client-side, setting it up is incredibly simple.

1. Clone the repository to your local machine:
   ```bash
   git clone https://github.com/your-username/smart-resume-analyzer.git
   ```
2. Navigate to the project directory:
   ```bash
   cd smart-resume-analyzer
   ```
3. Open `index.html` in your favorite modern web browser to start using the app. No local server or dependencies are required!

## Usage

1. Open the application.
2. Choose your input method:
   - Paste your resume text directly into the text area.
   - Upload your resume file (.txt, .pdf, .docx).
3. Click the "Analyze" button.
4. Review your personalized dashboard featuring your strength score, identified skills, missing keywords, and detailed improvement suggestions.
