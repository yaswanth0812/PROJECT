# Smart Resume Analyzer

Smart Resume Analyzer is a web-based resume analysis tool that helps users evaluate and improve their resumes quickly. Users can upload a resume, view an analysis score, identify detected and missing skills, receive improvement suggestions, and generate an AI-optimized resume preview.

## Features

- Upload and analyze resume files
- Extract resume content for review
- Generate a resume quality score
- Identify existing skills from the resume
- Highlight missing key skills
- Provide suggestions for improvement
- Display an AI-optimized resume version
- Download the optimized resume as a PDF
- Clean and simple user interface

## Project Preview

The application analyzes a resume and displays results such as:

- Resume score
- Identified skills
- Missing key skills
- Suggestions for improvement
- AI optimized resume
- PDF download option
